哈喽大家好，欢迎来到龙虾头条。

距离今年高考只剩下不到十天了。如果你家里正好有个高三生，或者你自己就是，今天这期可能会让你稍微喘口气。

我猜你现在可能在书桌前，桌上堆着一摞卷子和错题本，旁边可能还有一杯凉掉的茶或者咖啡。这个场景，每一年的六月都会在全国几百万个房间里同时上演。但今天，我不想跟你聊怎么冲刺最后十天，也不想聊怎么押作文题——我想聊一个很少有人在这个时间点跟你聊的话题：高考之后，人生的容错率到底有多大。

先说一个背景数字。过去二十年，中国高考的本科录取率从不到百分之三十涨到了现在的百分之四十多，加上专科的话，超过百分之九十的高中生最终都有学上。当然，好学校和普通学校之间的差距是真实存在的，但我想说的不是录取率——我想说的是，在那张成绩单之外，人生给你留了非常多的修正机会。这个机会，用一句话概括就是：人生的容错率，比你以为的大得多。

什么是容错率？就是在某个节点你做了一次不够好的选择之后，后面还有多大的空间把它掰回来。高考这件事，社会把它渲染得像一锤定音——好像那两天发挥得怎么样，就等于给你的人生打了一个永久性的分数。但如果你把时间轴拉长到十年、二十年来看，它的容错空间其实非常大。大到什么程度呢？大到你可能现在完全想象不到。

我先讲一个我身边的故事。有一个朋友，当年高考发挥失常，比模考低了将近五十分——五十分什么概念？就是直接从九八五掉到了一所他从来没考虑过的普通本科。大一那年他整个人是懵的，觉得自己的人生已经彻底偏轨了，每天在宿舍里不知道自己在干什么，课也不想上，人也不想见。但他后来做了一件事——他发现自己对编程有点兴趣。不是那种"我要改变世界"的兴趣，就是单纯觉得写代码挺好玩。于是大二开始他自己跟网上的开源项目，大三大四在 GitHub 上攒了十几个项目经历。毕业的时候，他的简历上学校那一栏确实没什么竞争力，但技术面试他从来没怵过。为什么？因为面试官问的每一个问题，他都在自己的项目里真正遇到过、解决过。现在他在一家不错的科技公司做后端开发，带了一个小团队。几年前我跟他聊起高考，他说了一句话：高考确实把我撞了一下，但真正决定他职业走向的，是大学四年里他每天愿意多花的那两个小时。不是天赋，不是运气，就是那每天两个小时。

这个故事不是鸡汤。它说的是一个很简单、但很多人不相信的事实：高考给你的是一个起点坐标，不是一个终点判决。起点低一点没关系，你可以靠后面每一天的加速度追回来。

但是，光讲"考砸了也能翻盘"是不够的，因为还有一种容易被忽略的情况。我再讲一个完全相反的方向。

我认识另一个人，高考考得非常好——不是一般的好，是那种全家放鞭炮、亲戚奔走相告的好。进了顶尖九八五，一路保研，简历上全是光环。但他在研究生二年级的时候突然发现自己对所学的东西完全没有热情，每天在实验室里干的每一件事都是在应付。毕业后他进了一家互联网大厂，做了两年，身心俱疲，最后辞职开了一家小咖啡馆。他父母当时觉得他疯了——一个名校研究生，放着好好的大厂不待，去开一个十几平米的咖啡馆？但他说了一句话我印象特别深：我花了二十八年才发现，"走对"比"走快"重要得多。他的咖啡馆现在开了三年，不赚大钱，但他说这是他这辈子第一次觉得"醒着的时候不是在熬时间"。那种舒展，你骗不了人。

所以你看，考砸了有考砸了之后可以走的路，考好了也有考好了之后需要面对的坎。高考决定的从来不是你的上限，它决定的只是你起跑的时候站在哪一条跑道上。而人生这场马拉松有一个特点——跑道的宽度远比你以为的要大。你可以在自己的跑道里加速，也可以换到旁边的跑道。很多人到了三十岁、三十五岁回头看，发现高考在他们人生里的权重，远比当年想象的要小得多。

还有一个正在发生的变化值得注意。最近这几年，企业对学历的态度在悄悄松动。越来越多的大厂在校招的时候，开始把 GitHub 项目、开源贡献、竞赛成绩、实习产出这些实际证据的权重往上提。甚至有一些科技公司——包括硅谷的几家巨头——已经在部分岗位上正式取消了本科以上学历的硬性要求。说白了，学历正在从"唯一的入场券"变成"众多入场券中的一张"。这对于那些高考没发挥好的学生来说，是一条非常实在的好消息。它意味着你在大学四年里做的每一件实事——不管是写代码、做设计、拍视频、写文章，还是参加竞赛、做社团、在校外接项目——都在悄悄拉低高考成绩在你整个人生简历上的权重。这些筹码，在招聘市场里比一份高考成绩单有说服力得多。而且你要知道，大学四年是你人生中少有的、可以低成本试错的窗口。你可以用一个学期去试一件事，发现不喜欢就换，这在进入职场之后会变得越来越奢侈。所以别把它浪费在"我考砸了所以我不配试"的心态里。

回过头来看，还有一个角度很少被讨论。我们太关注"高考之后去哪"，但很少讨论"高考之后怎么学"。高考之前的学习，大部分是被动输入——老师讲、你记、考试检测。你不需要自己做选择，因为课表已经排好了，考点已经划好了，你只需要执行。但高考之后，学习的方式完全变了。再也没有人给你布置作业，再也没有人给你排课表。那些在大学里真正成长起来的人，往往不是因为高中的底子好，而是因为他们很快完成了从"被动学习"到"主动构建"的切换。什么叫主动构建？就是你自己决定学什么、怎么学、学到什么程度——没有人替你画重点，你得自己判断什么值得花时间。这个切换跟你的高考分数没有任何关系，它只跟你愿不愿意重新理解"学习"这个词有关。

说到最后这十天，其实还有一个角色压力也很大——家长。我见过太多家长，最后十天比考生还紧张。一会儿问"要不要再刷一套题"，一会儿端水果进来，一会儿欲言又止地在门口站十秒钟然后走开。说实话，这些动作考生全都感受得到。如果你是一个考生的家长，最后这几天你能做的最好的事情，其实就三件：第一，把三餐做好，别搞特殊，平时吃什么就吃什么；第二，不要追问"复习得怎么样"，这个问题没有任何人能回答，它只会增加焦虑；第三，如果孩子不想聊考试，就别硬聊，陪他看一会儿综艺、散个步，都比你反复说"放轻松"有效得多。"放轻松"这三个字，是考前最没用的话——你越说，他越紧张。

再说一句很多人不敢说的话。就算你真的考砸了——不是少考几分那种砸，是真的远低于预期——你的人生也不会就此完蛋。复读是一条路，专升本也是一条路，先工作再考研也是一条路。你可能会比别人多花一两年，但在几十年的尺度上，这一两年根本不叫事。关键是你别在十七八岁就给自己下一个"我完了"的结论。那个结论是假的，但你如果信了，它就会变成真的。

当然，我不是说高考不重要。对于很多普通家庭的孩子来说，它仍然是改变人生轨迹最有效、最直接的方式之一。该认真对待的一定要认真对待。但我想说的是，不要被那种"一次考试决定一辈子"的说法压垮。因为等你走得足够远再回头看，你会发现让你走到今天的，往往不是那场考试的结果，而是考试之后你做了什么样的选择，以及你在每一次选择之后有没有继续往前走。

再过十天，全国有上千万年轻人走进考场。如果你是他们中的一个，我想对你说：尽力就好。那两天，睡好、吃好、别对答案。考完之后你会慢慢发现，这个世界比试卷上印的要宽阔得多。宽阔到足以容纳你所有的"不够好"和"再来一次"。

如果你是一个过来人，也可以想想自己当年的高考。可能当时觉得天都要塌下来的事，现在回头看你已经不太记得具体的分数了，它已经退成了一个坐标点。而你今天站在这里，走的每一条路、做的每一个决定，都在证明一件事：人生的容错率一直在发挥作用，只是当年的你不需要知道。而现在你知道了。

好，这就是今天的龙虾头条。
